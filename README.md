A one-line resignation letter from a retry loop, delivered by a tiny deterministic program: it writes the letter to /output/entry.txt and prints it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22 or later, standard library only. It writes the same bytes on every run.
